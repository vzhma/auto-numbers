# AUTO NUMBERS

Браузерная игра-коллекционер автомобильных номеров. Интерфейс адаптирован для мобильных экранов и подключает Telegram Web Apps SDK.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages** в репозитории `vzhma/auto-numbers`.
2. В поле **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** и запустите workflow **Deploy AUTO NUMBERS to GitHub Pages** (или дождитесь запуска после следующего коммита).
4. После успешного завершения откройте **Settings → Pages**: там будет адрес опубликованного сайта, обычно `https://vzhma.github.io/auto-numbers/`.

## Подключение к Telegram

1. Откройте [@BotFather](https://t.me/BotFather) и создайте бота командой `/newbot`, если он ещё не создан.
2. В @BotFather выполните `/newapp`, выберите бота, укажите название и короткое описание приложения, а в качестве URL укажите опубликованный HTTPS-адрес из GitHub Pages.
3. После сохранения откройте ссылку на бота и запустите Mini App. Для удобного запуска настройте кнопку меню бота через `/setmenubutton` и укажите URL опубликованной игры.

**Безопасность:** не добавляйте токен бота в HTML, репозиторий или сообщения. В этой версии прогресс хранится в браузере пользователя; общего аккаунта, серверной экономики и общего рейтинга пока нет.

## Локальный запуск

Откройте `index.html` в современном браузере. Для проверки Telegram Mini App используйте опубликованный HTTPS URL внутри Telegram.
